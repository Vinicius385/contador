# Contador

Aplicação web de contador desenvolvida utilizando HTML, CSS e JavaScript.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Incremento e decremento de valores
- Interface interativa
- Manipulação DOM
- Atualização dinâmica dos números
